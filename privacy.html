Privacy policy

Last updated 19 November 2026.

Find My Tracker is a personal app used only by its owner.

Google data

The app asks for one Google permission: access to files it creates itself in the signed-in user's Google Drive (the drive.file scope). It creates one spreadsheet and writes location rows to it. It cannot see, read or change any other file in the user's Drive.

What is stored and where

Location rows are written only to that spreadsheet, which stays private to the signed-in account. The Google sign-in token is kept in the macOS Keychain on the user's own Mac. Nothing is sent to the developer or any other server, sold, shared, or used for advertising.

Map page

The optional map page (/map/) runs entirely in the signed-in user's browser. It uses the same drive.file permission to read that one spreadsheet and draw it on a map; map tiles come from OpenStreetMap. The Google token is kept only in the open browser tab's memory and is never stored or sent to any other server.

Removing access

Sign out from the app's menu, or remove "Find My Tracker" at myaccount.google.com/permissions. Deleting the spreadsheet deletes the logged data.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
